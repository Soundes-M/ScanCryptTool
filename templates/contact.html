What is ScanCrypt?

ScanCrypt is a post-quantum cryptography security scanner that detects and analyzes ML-DSA and ML-KEM implementations in your codebase, identifying implementation vulnerabilities and security issues.

Which programming languages are supported?

ScanCrypt currently supports C and C++ source files. We scan local projects and analyze portable implementations, optimized variants (AVX2), and embedded/ARM Cortex-M deployments.

How do I get started?

You can start with our free Community plan by uploading a C/C++ project folder. You'll get immediate analysis of algorithm detection, security levels, and implementation types with an HTML report.

What's included in the Professional plan?

Professional includes unlimited scans, complete ML-DSA and ML-KEM rule packs, vulnerability detection, severity classification, PDF/JSON/SARIF export, and email support at €79/month.

Do you offer on-premise deployment?

Yes, on-premise deployment is available with our Enterprise plan. Enterprise also includes side-channel analysis, fault-injection detection, custom rules, API access, and priority support.

Can I test ScanCrypt for free?

Absolutely! Our Community tier is free forever and includes core analysis features, HTML reports, and up to 3 scans per day. No credit card required.
